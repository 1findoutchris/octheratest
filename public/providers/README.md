Place real, licensed provider logo assets here (e.g. `pragmatic-play.svg`) and
reference them from the corresponding provider's `logo` field in
`src/data/providers.ts`.

Do not add redrawn, modified, or placeholder logos that could be mistaken for
a real provider's trademark. When a provider has no logo file here, leave
`logo: null` in the data file — `ProviderLogo` automatically renders a clean
text-based placeholder mark instead.
